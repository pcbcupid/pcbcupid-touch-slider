# pcbcupid-touch-slider
Touch slider capable of handling 3 touch input with adjustable sensitivity!

<img src="https://files.pcbcupid.com/Documentation/Boards/g-sense/touch-slider/touch_slider1.avif" alt="PCBCUPID-Touch-Slider" />

This repo contains open source PCB files for PCBCUPID GSense Touch Slider Module <br/>
This particular PCB is designed using Kicad v9.0

**This design has been built and tested successfully!**
For more details, check out the product pages at

   * [Gsesnse-touchslider](https://shop.pcbcupid.com/product/gs004/)
   * [Docs](https://learn.pcbcupid.com/boards/g-sense/touch-slider)
